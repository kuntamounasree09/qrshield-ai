CRITICAL SECURITY RULES

QRShield must NEVER automatically navigate to a decoded URL.

Do not:
- open decoded URLs in the user's browser
- iframe untrusted URLs
- execute downloaded content
- execute JavaScript from decoded content
- expose server-side access to private/local network targets

Decoded QR content must be treated as untrusted input.

For URL analysis:
- allow only appropriate URL schemes
- block localhost/private/link-local/reserved addresses
- prevent SSRF
- limit redirects
- use short request timeouts
- validate every redirect target
- handle malformed URLs safely

For uploads:
- validate MIME type
- validate file signature where possible
- enforce file-size limits
- reject unsupported files
- do not execute uploaded files

AI and threat-intelligence failures must degrade gracefully.

Do NOT create fake threat-intelligence results.

Do NOT create fake AI results.

If optional services are unavailable, clearly report that they are unavailable and continue with deterministic analysis.
